# Dark House Audio

Repository for the Dark House Audio website.

## Website

Visit the website at [https://darkhouseaudio.github.io/darkhouseaudio/](https://darkhouseaudio.github.io/darkhouseaudio/)

## Structure

- `index.html` — Home
- `store.html` — Product store
- `product-landing.html` — BleedShift 2 overview
- `bleedshift2.html` — BleedShift 2 product + checkout
- `contact.html` — Contact
- `thank-you.html` — Post-purchase
- `tos.html` — Terms of Service
- `css/style.css` — Shared design system
- `js/main.js` — Shared interactions
- `rider/` — Afterglow technical rider
- `audio/` — Audio demo files
- `icons/` — Favicons

## Features

- Audio plugin showcases (BleedShift 2)
- Professional mixing and mastering services
- Product store with PayPal checkout
- Contact information
- Waveform audio demos (WaveSurfer.js)
