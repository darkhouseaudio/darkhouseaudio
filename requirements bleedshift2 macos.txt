Recommended Specifications (for GPU Acceleration via MPS):
Operating System: macOS 12.3 or later (This is essential for the Metal Performance Shaders backend used by PyTorch for GPU acceleration).
Processor/Graphics:
A Mac with Apple Silicon (M1, M2, M3 series chips, etc.)
OR An Intel-based Mac with a compatible AMD dedicated GPU.
(Note: Macs with only Intel integrated graphics cannot use MPS acceleration).
RAM: 16GB or more is strongly recommended. While it might run on 8GB, processing larger audio files or more complex models can be memory-intensive, and more RAM (especially the unified memory on Apple Silicon) significantly improves performance.
Storage: Sufficient free space for the application itself (the .app bundle can be several hundred MBs due to included libraries) plus space for your input audio files and the generated output stems.
Minimum Specifications (for CPU-Only Operation):
Operating System: macOS 12.3 or later (Even for CPU, this ensures compatibility with the libraries used and the build environment).
Processor: Any Apple Silicon or Intel processor capable of running macOS 12.3+.
RAM: 8GB (Processing will be significantly slower than with GPU acceleration, and you might encounter issues with very large files).
Storage: Same as recommended.
In short: To get the intended performance benefit using the Mac's GPU, you need macOS 12.3+ and either an Apple Silicon chip or a dedicated AMD GPU. The application will still run on other Macs meeting the minimum OS requirement, but it will fall back to using the CPU, resulting in much longer processing times.
